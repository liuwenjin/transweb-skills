# Documentation

## Beginner manual

- [transweb-ai 使用说明书（HTML）](transweb-ai-manual.html) — A4 print-friendly, no terminal commands
- [transweb-ai 使用说明书（PDF）](transweb-ai-manual.pdf) — 16 pages, A4
- [Manual assets](manual-assets/) — source screenshots

The beginner manual focuses on:

1. creating an API key on transweb.cn;
2. handing the key to an AI assistant for local configuration;
3. asking the AI to list apps, run tasks, and generate PPT;
4. security and troubleshooting.

## Notes

- API keys are never included in this repository.
- `selftest --json` works without a key or network.
- The manuals are platform-neutral; they do not require a specific agent client.
